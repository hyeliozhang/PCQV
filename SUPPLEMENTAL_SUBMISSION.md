# Supplemental Material Notes

This package contains the manuscript PDF/source, reproducibility artifact, generated results, and local verification gates.

Recommended entry points:

1. Read `paper/main.pdf`.
2. Run `python artifact/verify_final_claims.py` from the repository root.
3. Inspect `EVIDENCE.md` for claim-to-file mapping.
4. Inspect `REPRODUCIBILITY.md` for local and containerized reproduction commands.
5. Inspect `ARTIFACT_VALIDATION.md` for the package-level validation summary.

The package is CPU-only and uses Python/SQLite. It does not require a GPU, server DBMS, paid API, or external network service.
