# Supplemental Submission Notes

This package contains the paper source, final PDF, reproducibility artifact, and generated results.

Recommended reviewer entry points:

1. Read `paper/main.pdf`.
2. Run `python artifact/verify_final_claims.py` from the package root.
3. Inspect `SUBMISSION_AUDIT_REPORT.md` for the final review and repair log.
4. Inspect `EVIDENCE.md` for claim-to-file mapping.
5. Inspect `REPRODUCIBILITY.md` for local and containerized reproduction commands.

The package is CPU-only and uses Python/SQLite. It does not require a GPU, server DBMS, paid API, or external network service.
